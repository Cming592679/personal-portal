# Personal Portal

一个本地运行、个人数据独立存储的个人管理工具。

代码公开，数据私有。日常使用只有两个动作：**记下要做的（Task）**，**记下发生的（Daily）**。

---

## 快速开始

```bash
# 1. clone 代码
git clone <repository-url> personal-portal
cd personal-portal

# 2. 安装依赖
npm install

# 3. 配置个人数据目录
cp .env.example .env.local
#    编辑 .env.local，设置：
#    PERSONAL_DATA_DIR=/home/<you>/personal-portal-data

# 4.（换电脑时）把旧电脑的个人数据复制到该目录
#    personal-portal-data/portal.db、personal-portal-data/task-logs/ 等

# 5. 启动
npm run dev
# 打开 http://localhost:3000
```

> **代码与个人数据永久分离**：代码在 Git 仓库里，个人数据在 `PERSONAL_DATA_DIR` 里，两者互不相混。GitHub 上永远看不到你的个人数据。

## 页面定位

| 页面 | 路由 | 定位 |
|------|------|------|
| 仪表盘 | `/` | **回顾**：习惯打卡、备忘、统计图表、日历热力 |
| 工作台 | `/workbench` | **当下操作**：建任务、管任务、记 Activity、记心力 |
| 日常 | `/daily` | **历史**：本周四象限概览 + 按日期查看/修改过往记录 |
| 心智 | `/mental` | 知识库搜索 + 快速笔记 |
| 职业 | `/career` | 目标方向 / 思考笔记 / 调研学习 / 尝试实践 |
| 身体 | `/body` | 身体目标与优化建议 |

| 设置 | `/settings` | 预算 + 数据导出 |

侧边栏只保留一级入口。「日常」从工作台或侧边栏进入。

## 每天怎么用（工作台）

打开网站直接进 **工作台**，一页完成三件事：

1. **建 Task**：输入标题，点选分类（工作/心智/身体/精神）和优先级（高/中/低），Enter 添加。分类和优先级在创建时就定好，之后随时可改。
2. **记 Activity**：输入框自动换行，Ctrl/Cmd+Enter 或点按钮提交，想到就记。
3. **记心力状态**：点「枯竭 / 还行 / 活力无限」，自动写进当天 Activity（「记录心力状态：X」）。

**当前任务**在左栏：显示优先级、可拖动排序（把想先做的放上面）、点击展开写备注（自动增高，收起时有 📝 预览）、状态下拉切换、可删除。「最近已完成」默认收起显示 7 条，展开显示近 30 天，更早的到仪表盘日历按日期回顾。

```
想到一个明确要做的事        → 建 Task（选分类 + 优先级）
正在推进这件事              → 正常推进
过程中发现的信息/命令/问题/想法 → 记一条 Activity
事情完成                    → 状态改为「已完成」
```

## Task 怎么用

- **创建**：工作台输入标题 → 选分类/优先级 → Enter。
- **排序**：拖动任务行调整顺序（持久化）。
- **备注**：点行左侧展开箭头，写多长都可以，失焦自动保存。
- **状态**：行内状态下拉（待办 / 进行中 / 已完成），或从「最近已完成」改回来。
- **日志**：工作台「当前任务」卡片右上角「日志」，查看所有任务的操作历史（创建/状态变更/备注/删除）。
- **优先级**：🔴 高 / 🟡 中 / 🟢 低，创建时选定，行内可改。
- **截止时间**：数据库字段已预留，UI 暂未提供入口。

> **Task 和 Activity 的区别**：Task 是「要做的事」，Activity 是「已经发生的事」。解决同一个问题时，Task 只有一条，但过程中可以记很多条 Activity。

## Daily 怎么用

Daily **不是日记**，是低摩擦的「发生记录」。可以记任何东西：做过什么、学到什么、一个想法、一个要处理的问题、Debug 过程、生活琐事。

- 顶部「本周概览」：按四象限（工作/心智/身体/精神）统计本周完成任务数，加上 Activity 条数、习惯完成率、心力均值（纯统计，非 AI）。
- 输入 → Enter → 完成，记录在当天时间线下。
- 按日期筛选查看过去某一天，或直接看全部（按天分组、倒序）。
- 记错了可以删除（悬停条目，点右侧 ×）。

> Daily 第一阶段的目标是「留下痕迹」，不是「立即整理」。先记下来，整理是以后的事。

## 仪表盘怎么用

- **DAILY HABITS**：当天习惯打卡（运动/阅读/早睡等），点击切换。
- **SCRATCHPAD**：购物清单 + 备忘，存在浏览器本地。
- **ANALYTICS**：记录天数、完成率、维度达标雷达、习惯完成率柱状图。
- **日历**：格子底色 = 当天心力（红/黄/绿），图标 = 习惯打卡，✓n = 当天完成任务数。点击某天可修改心力、补打卡习惯、查看当天完成任务。

## 身体 / 精神页

- **身体**：记录体重/睡眠/运动已不在本工具内（交给体脂称/手表 App），页面只保留「身体目标 / 优化建议」。未来 Daily 每周分析会在这里生成优化建议。
- **精神**：联系人 + 联系记录；超过 30 天未联系会在顶部汇总提醒。「精神目标 / 提醒」可记类似「读完《被讨厌的勇气》」「找妈妈聊聊天」这类事。

## 数据与迁移

- **代码**：`git clone` / `git pull`
- **个人数据**：`PERSONAL_DATA_DIR` 指向的目录
- **换电脑**：clone 代码 + 恢复个人数据 + 配置路径，即可

```
PERSONAL_DATA_DIR/
├── portal.db        # SQLite（Task / Activity / 笔记 / 习惯 / 联系人 …）
├── task-logs/       # 任务日志月度导出（json / md）
└── future-data/     # 未来：attachments / exports / media …
```

真实路径写在本地 `.env.local`（已被 gitignore），仓库只提交 `.env.example` 示例。

> **裁剪说明**：记账 / KPT 回顾 / 订阅 / 运动记录 / 体重睡眠 / 心力趋势已从界面移除，但对应的数据表和 API 都保留，历史数据不丢失，可通过设置页「导出 JSON」备份。
