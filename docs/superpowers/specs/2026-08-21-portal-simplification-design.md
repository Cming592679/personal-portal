# Personal Portal 简化重构设计（2026-08-21）

## 背景与目标

用户对 `origin/main` 上"魔改版"（07198a7 → 846bc9a，已保留到本地分支 `archive/mogai-origin-main`）不满意，已把本地回退到 `339f355`。本设计在 `339f355` 基础上按用户新需求重做：

- 工作台成为唯一"当下操作"中枢：建任务（带分类/优先级）、管理当前任务（拖动排序、备注、状态）、记录 Activity、记录心力状态。
- 仪表盘瘦身为"回顾"页：习惯打卡 + 备忘 + 统计图表 + 紧凑日历。
- 日常页保留为历史时间线 + 本周四象限概览。
- 身体/精神页改造为"目标与建议"空间；精神页同时保留联系人并加未联系提醒。
- 心智/职业/设置页本轮不动。
- 裁剪功能只去掉 UI，**不删任何历史数据**（API 与数据表保留）。

## 页面定位

| 页面 | 定位 | 主要变化 |
|---|---|---|
| `/workbench` 工作台 | 当下操作 | 重写：两栏 50/50，完整任务管理 + 记录 + 心力 |
| `/` 仪表盘 | 回顾 | 移除四象限/TASKS/TOOLS/支出；重做日历 |
| `/daily` 日常 | 历史 + 周概览 | 增加本周四象限概览卡片 |

| `/mental` `/career` `/settings` | 不动 | — |

## 工作台设计

布局：去掉 `max-w-5xl` 限宽，`lg:grid-cols-2` 两栏各 50%。

左栏：
- 新任务卡片：标题输入 + 象限 4 选 1 按钮组（工作/心智/身体/精神）+ 优先级 3 选 1 按钮组（高/中/低）+ 添加按钮，Enter 提交。
- 当前任务卡片：待办+进行中按 `sort_order` 混合排序；每行含拖动手柄、优先级图标、标题、象限图标、状态下拉、删除；点击展开备注（自动增高 textarea），收起时有备注则显示 📝 单行预览；卡片头部含任务日志入口。
- 最近已完成（当前任务卡片内折叠区）：默认显示最近 7 条，展开显示最近 30 天，更早的提示去仪表盘日历回顾。

右栏：
- 心力状态卡片：枯竭/还行/活力无限 三选，点击写入当天心力并自动在活动流留一条「记录心力状态：X」。
- 记录卡片：自动增高 textarea，Enter 换行、Ctrl/Cmd+Enter 提交，另有按钮。
- 最近 Activity 卡片：最近 10 条 + 查看全部（去 `/daily`）。

## 仪表盘设计

- Hero：日期 + 今日心力状态展示（未记录时提示去工作台）+ 习惯完成 + 待办/进行中计数（去掉支出）。
- 移除：四象限入口、任务看板、TOOLS（记账/KPT/订阅）、心力快选按钮。
- 保留：DAILY HABITS 打卡、SCRATCHPAD、ANALYTICS 图表。
- 日历重做：紧凑固定高度格子（约 h-10）、日期数字加大、习惯用清晰小 emoji（最多 3 个，超出显示 +N）、能量底色、当日完成任务数小标记；整屏放下无需滚动。点击某天弹窗：编辑能量 + 习惯打卡 + 查看当天已完成任务（新增 `/api/tasks?completed_date=` 支持）。

## 日常页设计

- 顶部新增「本周概览」卡片（新增 `/api/weekly`）：本周各象限完成任务数、Activity 条数、习惯完成率、心力均值（纯统计，非 AI）。
- 保留：输入框（记今天）、日期筛选、按天分组时间线、删除。

## 身体 / 精神页设计

身体页：
- 移除运动记录、身体数据（体重/睡眠）、心力趋势。
- 新增「身体目标 / 优化建议」卡片（复用 notes，`tag=body-goal`）。
- 占位卡片：未来 Daily 每周分析在此生成身体维度优化建议。

精神页：
- 保留联系人 + 联系记录。
- 新增「精神目标 / 提醒」卡片（`tag=spirit-goal`）。
- 新增未联系提醒：`last_contact` 为空或超 30 天的联系人高亮并汇总提示。

## 数据与 API

- 保留所有表与 API；`transactions/reviews/subscriptions/exercise_logs/body_metrics` 只裁 UI。
- `POST /api/energy`：date 为今天时自动插入 activity_logs（同一天同一状态不重复写）；历史补录不写。
- `GET /api/tasks` 增加 `completed_date` 查询参数（日历查看当天完成任务）。
- 新增 `GET /api/weekly`：周一起的四象限完成数、Activity 数、习惯完成率、心力均值。
- 时间相关使用本地日期（Asia/Shanghai），不在新代码里用 `toISOString().split("T")[0]` 取"今天"。

## 明确不做（YAGNI）

- 不做 AI Weekly Review（保持规划，仅做纯统计概览）。
- 不新增测试框架（项目无测试基建，验证用 lint + build + 路由 smoke）。
- 不裁心智/职业/设置页；不删任何历史数据。
- 不做任务截止时间 UI（字段已预留）。
